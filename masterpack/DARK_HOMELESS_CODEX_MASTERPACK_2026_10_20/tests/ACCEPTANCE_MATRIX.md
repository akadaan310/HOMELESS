# QUANTIFIABLE END-TO-END ACCEPTANCE / BUILD EVIDENCE

This is the acceptance harness. Targets are **design criteria, not pre-existing achieved metrics**. Every check yields `{check_id, build_hash, env, data_revision, procedure, oracle, observed, threshold, status, logs, witness_hash, confidence?, blocker?}`. A screenshot by itself never establishes correctness. Frame buffer readbacks, ray probes, G-buffer, physics traces and spectrograms may serve as numerical evidence. A final human art review complements, not replaces, instrumented tests.

## Automated research phenomena

After all achievable build tasks, emit `findings.jsonl` with hypotheses, candidate surprising correlations, measured evidence, reproducible fixture, accepted/rejected status, and potential next experiment. If model finds a rare sky/route pattern, it must calculate an explicit null reference and holdout test before calling it a certified discovery. A missed metric becomes a failing result or explicit environment blocker; a prose narrative is not success.
