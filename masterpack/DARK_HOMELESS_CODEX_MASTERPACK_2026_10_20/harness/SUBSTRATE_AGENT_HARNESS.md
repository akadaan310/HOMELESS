# SUBSTRATE EXECUTION HARNESS — CODEX / IMPLEMENTING AI

**This is executable build authority, not a conversational report request.** Interpret user requirements as the product north star. Create program code, datasets adapters, tests, Unreal project, scene, Android/browser outputs, and measured evidence in one uninterrupted run where environment permits.

## Operating process

1. Read all pack docs, inspect input archives safely, sample executable source and test results. Produce a structured `SOURCE_RECONCILIATION.json` before modifications. Resolve conflicts with priority `current user requirements > current PRD > new interface designs > previous tech packs`. Example: prior V3 game bible says Dark is fictional; CURRENT direction says Dark is Abed, the real founder/player. Do not propagate the old identity.
2. Detect actual environment: OS; UE version/editor availability; C++ toolchain; Android SDK/JDK/Gradle; UE cooking facilities; GPU/encoder; Python, Node, Octave, git; internet; source asset access; local/native IPC. Report in a machine manifest; never invent a resource.
3. Build workspaces as modules with existing user repos treated as upstream reference; no destructive overwrite. Read default branches, actual paths and test suites before porting logic.
4. Build cross-domain kernel and typed protocol first, then Unreal adapters/scene and ingest, then audio/camera/world features, then Pixel Streaming + Android APK, then full validation. Perform implementation concurrently where independent and tools allow. Do not stop after phase planning.
5. Develop **full-world schemas and tests from outset**, not a Tampa-only hard-coded application. High-quality focused close scenes are a rendering budget tactic, not a conceptual or geographic limitation.
6. Compiler of grammars: create, validate, reject bad examples, promote typed forms and fold/unfold them. Integrate existing In-Grammar and REALMS code via tested adapters, upgrading rather than deleting work.
7. Runtime shell is mandatory; demonstrate actual `ash`/Wasm/QuickJS/`darkctl` execution and IPC continuity, not only a facade. Perform bounded scripts and keep effects typed/explicit.
8. Octave is math oracle for reference runs and numerical test vectors. UI/render runtime uses fast bounded solutions. Select solver and log numeric evidence, not hand-wave choices as deterministic.
9. Acquire and ingest high fidelity Unreal source assets with manifest/state proof. If tool environment can't download a source, preserve actual retrieval commands and accurate unavailable status; continue with accessible quality sources. Don't replace unavailable imports with low-fidelity final scenes.
10. Produce reproducible first-run video/interactive test, quantified capture/frame/buffer telemetry, functional APK if toolchain permits; do not claim unbuilt files.

## Epistemic semantics

For every observation/research claim tag `[known]`, `[constructed]`, `[measured]`, `[hypothesis]`, `[refuted]` and keep a `COUNTEREXAMPLES.md`. Distinguish source-derived measured facts from synthetic test fixtures. Every algorithm report includes domain/observable, non-conforming forms, optimization cost, data revision, reference code, held-out test, experimental controls and failure modes. Mathematical novelty is never inferred solely from a poetic name.

## Engineering North Star

The full game world must remain vibrant with a single human player: autonomous background life, credible mixed group activity, events initiated by inhabitants, ambient transport, cinema and natural sound. The world can create new *certified* generative structures through typed participant contributions while avoiding model hallucination. The engine independently exposes all domains through a programmable operations surface.

## Team/agent execution

Codex may use parallel subagents for geospatial, C++/UE, world grammar, mathematics, audiovisual, Android/server, data ingestion and tests; each subtask has real file/diff/tests, shared stable interfaces and no infinite planning loops. Prioritize compiling artifacts over excessive theoretical prose. Unit tests early. Repair failures. If a tool or environment is missing, build source, mocks labelled as mock, smoke tests, provisioning scripts and clear execution blockers; never falsely report compiled Unreal 3D or installed APK.

## Substrate discovery return

Once deliverable is built, agent must return **both** product status and research ledger: which reusable new grammar letters/macros were discovered, what tests demonstrate them, failed hypotheses, cross-domain correspondences that survive invariance tests, actual performance improvements or regressions, a next-experiment shortlist. This is not permission to continue making uncontrolled changes after delivery.

## Anti-distraction

Do not switch to Godot or a low-quality engine. Do not substitute generated placeholder-looking scene as final art. Do not treat GitHub branch `main` as universal. Do not add fake API endpoints or pretend arbitrary URI schemes are natively supported by stock curl. Do not claim eight billion concurrently thinking agents. Do not claim 'infinite' RAM, precomputed all Earth paths, physically moved real cities, or discovered astronomical constellations when a name lookup was used. Work autonomously to accomplish the highest verified deliverable.
