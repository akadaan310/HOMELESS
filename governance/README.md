# Constitutional admission subset

Implements HD-005.1 as a bounded JSON policy projection, not a complete prose compiler or world authorization service. `cop.py` defines lexical limits, registered boolean predicates/operations, budgeted verdicts, rejection witnesses and test obligations. Policy digests use canonical JSON. Compile-time checks reject unresolved symbols, duplicate/overlapping definitions and direct contradictions; arbitrary logical contradiction solving is not implemented. Supersession is not implemented: unsupported revisions are refused. No founder provisioning or distributed credentials are supplied by this subset.

Run `python3 -m unittest discover -s governance -p 'test_*.py'`. The two compilations in the determinism fixture are the same implementation; they do not satisfy the independent-evaluator requirement. World writes still require a separate authenticated admission/commit adapter. Native experiential clauses remain outside this DSL.

`requirements.json` projects all 100 top-level sections. Subclauses retain their normative force in the commission; an initial top-level row is not proof of full subclause coverage. Statuses remain NOT_RUN until evidence supports a narrower claim. `PATCH_PLAN.md` maps current batches before editing.
