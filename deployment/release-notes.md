HOMELESS Rendezvous engineering preview

This prerelease contains a signed Android development APK, a PlayCanvas/Rapier browser build, and native Linux runtime fixtures. The repository contains the persistent World Loom service, typed Grammaticals and predictive gates, source-asset pipeline, numerical and geography/astronomy witnesses, and the Unreal 5.8 source integration.

The connected build supports free walking, independent cached neural NPC speech, reviewed speech/text intents, optional mission acceptance and haven reports, computational billboards, and durable authoritative events. The static browser bundle is explicitly a cached origin replay until a real HTTPS world service is configured. The APK uses the same client and requires that separate service for new authoritative events and ASR. No Oracle service is deployed.

Verification: 98 Python tests, 12 Node tests (including actual Rapier WASM collision), an 11-channel daemon test with forced restart and duplicate retry, actual Chromium walk/reload/audio evidence, and Android package/signature inspection. The final minor input/telemetry delta after the full browser run is recorded in evidence/web_checks.json. All 90 web files embedded in the final APK match the final browser build. Details, hashes, measurements, negative research results and the full acceptance ledger are committed in the repository.

This is a development build signed with an Android debug certificate. Full commission acceptance is FAIL: Unreal cooking/GPU streaming and physical Android/Oracle tests are blocked; visual completeness, software-renderer frame time and Arabic ASR quality have unmet gates. See evidence/acceptance.md and docs/DELIVERY.md for precise limits. No AAA, Samsung FPS, Arabic recognition, identity-federation or actual Unreal rendering success is claimed.

The original masterpack-v1 release and all attached source packs remain unchanged.

Downloads are committed repository artifacts. The separate GitHub release-upload endpoint returned HTTP401, so no uploaded release attachments are claimed.
