# Local authority and continuity

`python3 -m worldloom.cli daemon` exposes `.runtime/worldloom.sock`, mode 0600, using a four-byte network-order size followed by canonical CBOR. The local engine needs no HTTP service. `darkctl query purl://dark/world/state`, `darkctl time`, `darkctl checkpoint`, and JSON `invoke` exercise actual IPC.

SQLite uses WAL and synchronous FULL. ACK follows commit. Event IDs are idempotent only for identical canonical content; changed content conflicts. Event hashes chain canonical semantic events, not GPU frames. Checkpoints include the projected state digest. Replay is restricted to `continuity.read`; public PURL reads omit private session histories. Corrupt chains are detected before append/checkpoint. Single-host serialization is the current scope; multi-host consensus is not claimed.

A string identifying Dark grants nothing. The first local store creates a random operator capability in a mode-0600 `.operator-token` beside the DB. Keep it local; it is never bundled with web/APK artifacts. Scoped grants bind actor, effect names, expiration and revocation. The operator token is bootstrap operator authority, not independent verification of Abed's real-world identity. Production founder account federation remains a deployment requirement.

Pure `query`/`resolve` do not log or commit. `propose` does not mutate. Only typed `commit` with valid authority admits effects. Grammar validation never upgrades authority. Media preparation is separate from world activation. Transcripts, shell stdout and neural text cannot directly mutate the world.

Historical reconciliation: PURL repository default branch `claude/purl-protocol-research-bxevq5` defines PURL/0.1 HTTP manifests and scoped bearer grants. SEURL's `master` defines START/SWITCH/WRITE/COMMIT/BUILD/TALK/PERTURB in a standalone browser instrument. The commission's domain SEURL channel family is therefore a new adapter, not a claim that historical SEURL already implemented audio or physics. SubstrateIO's ACSP export reader and pure computational address practices inform this implementation. Exact heads and rerun logs are under `evidence/`.

The shell runs BusyBox ash in bubblewrap with an empty environment, private writable `/work`, no host root and its own network/PID namespaces. Statically compiled `darkctl` talks to a job-specific broker; edits are proposals only. The `curl` entry routes an allowlisted conventional HTTPS fetch through a broker executing stock curl with bounded output/time and the inherited proxy. It does not teach stock curl new URI schemes. QuickJS and Wasmtime have no host filesystem or network bindings; their typed returned events remain proposals. These worker mechanisms require Linux bubblewrap/user-namespace support; other platforms need an equivalent isolation adapter.
