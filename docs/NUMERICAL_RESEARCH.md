# Bounded numerical authority and sensory fixtures

[K] Convex diagonal quadratic optimization has a global certificate when feasible bounds and signed KKT stationarity hold. The C++ kernel implements this restricted family, not an unrestricted general optimizer. [C] It supports at most 256 coordinates, deterministic lexicographic policy, IEEE754 binary64 and no fast math. Inconsistent bounds return `infeasible`; negative curvature is `unsupported`; an unconstrained linear descent direction is `unbounded`. Fixed coordinates admit either gradient sign. Every result includes the problem-dependent witness hash, status, residuals, units and operation count. Measurements of time are excluded from the reproducibility hash.

[K] Classical RK4 approximates `dy/dt=-rate*y`; the independent Octave fixture uses adaptive `ode45`, and an analytic solution supplies a third witness. [C] The runtime refuses more than 100,000 steps and unstable fixture step products `rate*dt>1`; it labels a result `approximate-feasible`, never globally optimal. Pure-strategy finite-game enumeration is limited to 8×8 actions. Multiple equilibria are `ambiguous-equilibria`; matching pennies has no pure equilibrium and is reported `not-converged` with an explicit mixed-strategy limitation. Bargaining records separate actor utilities, reservations, possible refusal, minimum-surplus objective and action-id tie break. Empty acceptable sets are recorded rather than inventing agreement.

[M] Run `python -m worldloom.numerics` to compile the shared library and executable and regenerate actual Octave/native comparisons, CPU timing, 24/30/60/90fps traces and field witnesses. `math/reference_octave.m` runs with GNU Octave 9.4.0 in this environment via `.cache/bin/octave`. Production APIs are `solve_box_qp`, `solve_decay_ode`, `solve_game`, `negotiate`, `camera_trace`, `weather_field` and `overview` in `worldloom/numerics.py`.

[C] Camera integration uses a fixed 720Hz lattice, bounded acceleration ±6m/s², jerk ±25m/s³, speed ±10m/s and a ±20m corridor. Display frames sample that same authoritative lattice. The controlled direct-follow baseline sees the identical synthetic target and time grid. The traces report p95/p99 jerk, normalized tracking error and analytical corridor violations. Modes expose distinct camera offsets. [M] Common integer timestamps coincide across tested render rates; jerk improves over direct follow. [H] That improvement produces better perceived cinematography in a real street scene: untested. Zero roll is a property of this scalar fixture, not a measurement of horizon pixels. Framing uses a scalar normalized tracking proxy. Occlusion, scene-mesh collision, stream packet jitter and image-space framing require renderer integration and are not passed by these tests. Finite jerk also causes substantial lag on this aggressive fixture; the recorded normalized tracking error is about 0.33, and no claim of ideal composition follows from low jerk.

[K] The weather field derives from a compact support streamfunction, so continuous divergence is zero by equality of mixed derivatives. [C] The game field uses a 2m/s base wind plus at most 3m/s tangential swirl with smooth support. Analytic vorticity and central-difference divergence are both emitted. Wetness evolves with the exact bounded solution of `m'=rain*(1-m)-.06*m`. Roughness is `.82-.64*m`; reflectance is `.04+.35*m`. [M] The exported field includes numerical wind, vorticity, wetness and material parameters; renderer light-buffer and VFX response remain separate gates. The field is an authored fictional perturbation, not a forecast, disaster simulation or solution of full atmospheric Navier–Stokes.

[C] The audio fixture generates real PCM16 stereo sources for engine, traffic, voice, pedestrian, airplane, music and weather. Every stem has a positioned equal-power pan, distance attenuation and optional stable low-pass occlusion. Voice prefers the actual Piper catalog when available; an eSpeak diagnostic fallback is clearly tagged. Integer sample scheduling, fades, peak, RMS, stereo correlation, heavy adjacent-sample changes and simulated buffer dispatch lateness are recorded. These are offline sample measurements; LUFS, interpolated true peak, HRTF localization, in-engine A/V sync, human audition and Samsung dropout/onset are not claimed. The cue policy has a salience cap, cooldown and permanent suppression after decline/ignore within its provided state. Event sources exist independently of any response.

Run `python -m unittest discover -s tests` for the repository suite. Regenerate audio with `python -c 'from worldloom.audio import render_soundscape; render_soundscape()'`; generated WAV files and `manifest.json` are under `artifacts/audio`. Re-run after voice generation so the voice stem uses the neural catalog. The manifest distinguishes diagnostic from neural speech and pins all generated source bytes.
